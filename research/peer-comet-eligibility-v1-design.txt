Decision supported by this package

The dry CLI validates the proposed request manifest and prints zero requests
permitted. Its settled source/test/design pins require exact fixed paths,
lengths and SHA256 hashes; missing pins remain explicitly pending, and a
symlink or mismatch fails. These local checks confer no network authority or
deployed artifact equivalence. The injected-stream engine is for synthetic offline tests. It has no
HTTP adapter, endpoint discovery, live flag, output directory, wallet, signed
transaction, deployment or persistent run claim. It must not be used for live
collection without a separately reviewed adapter, exact source/test/protocol
pins, root commit, raw allocation and immutable exclusive one-run claim.

The engine retains three separate concepts: returned ABI eligibility claims,
checked runtime fingerprints matching a supplied certificate, and source equivalence.
It never independently proves the last concept. With no certificate, even a
well-formed favorable transcript ends source_binding_unavailable. A synthetic
certificate stays labeled synthetic_fixture_only. Certificate kind and review
reference are caller-supplied claims; the collector never establishes their
authority. Matched and unverified role lists remain explicit: an ineligible
path checks six roles and leaves factory/pool unverified; a favorable path
checks eight. Even eight matching roles do not prove transitive dependency
closure or source equivalence. Any actual external review must bind the exact
artifact set; a certificate string or source branch name proves neither.
The code never reports cash_closed, profit, execution or inclusion.

Prospective request manifest

The JSON plan carries all 31 request templates, including method/params and
fixed substitutions. There is one latest header selection, then ordinary
state reads require its blockHash with requireCanonical=true. The original
number's header and implementation slot are rechecked last. Numeric-parent
eth_simulateV1 cannot eliminate a reorg-out-and-back interval; this limitation
is explicit. No retries, endpoint fallback, fee-tier search or replacement
contract discovery is allowed.

Requests 1-11 establish chain, parent, code fingerprints, proxy/AssetList and
the fixed base/collateral identities. Requests 12-15 add USDC transitive identity.
Requests 16-19 collect all parent gate views. Request 20 runs all four views in
one conditional child with validation false, gas 200000 each, zero value,
explicit zero synthetic sender and no state
overrides. This is eth_call-like metadata, not a successful transaction proof.
All four receipts are retained even when a call fails. The child is exactly
parent.number+1 with the earliest 12-second slot-grid timestamp at least 400ms
after the recorded decision and at least one slot after the parent. Skipped
slots are possible; actual inclusion is not established.

Only a favorable child gate claim selects requests 21-28: fixed canonical V3
factory code, getPool(USDC,WETH,3000), resulting pool code and its factory,
token0, token1, fee and signed int24 tickSpacing. Require USDC/WETH/3000/60.
The factory proves the chosen pair, not cheapest observed price. Requests 29-31
recheck USDC/Comet implementations and parent. A normal ineligible path uses 23
requests, a favorable path 31; a malformed/resource path preserves its failing
prefix and cannot claim completed canonical verification. All later pool
requests remain recorded as structurally unselected, not negative observations.

No oracle value, slot0, price, liquidity quote, quoteCollateral, swap, history,
borrower cohort or economic amount is in this manifest. Missing evidence stays
unavailable. Positive inventory means stock exists, not a particular order
size can be filled. Known pause/no-stock/target gates are conditional returned

Resource and failure contract

The prospective maximum is 31 calls, 65536 response bytes per request,
524288 cumulative body bytes, 524288 in-memory trace bytes and 120 seconds with 10 reserved
for completion. Each read is bounded by remaining cumulative allowance; an
exact exhausted boundary without EOF fails. There is no retry after failure. The in-memory trace ceiling covers eight
large runtime responses; it is not a raw-storage allocation. No trace file is
written by this draft, and future retained/raw caps need separate root review.
Duplicate/nonfinite/deep JSON, noncanonical ABI, wrong chain/context, bad pool
identity or certificate mismatch terminates the selected prefix. Header
projections omit unrelated transaction hashes while preserving body length
and digest. Terminal accounting space is reserved before admitting a request.
An eventual network adapter still needs a hard per-request/overall deadline,
no redirects/environment proxies and persistent exclusive publication; the
offline engine's clock checks are not a slow-drip network timeout guarantee.

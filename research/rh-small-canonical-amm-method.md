# Frozen small canonical AMM quote screen

Frozen before any new quotes, 29 September 2026 UTC. This is a read-only screen for **canonical Robinhood Chain ERC-8056 stock tokens** against USDG Uniswap pools and Hyperliquid `xyz` perpetual books. It is separate from the RH-domain Lighter perp maker pilot. No order, signing, wallet, transaction, bridge, or VPN is used.

## Selection and cap

- Assets, fixed before quotes: **NVDA, AAPL, MSFT, TSLA**. Sizes: **$100, $250, $500, $1,000**. Five rounds, at least 65 seconds apart.
- Start from the archived [Dexscreener pool index](../data/raw/robinhood_all_pools_20260929T035521Z.json). For each asset, select the highest indexed-liquidity direct token/USDG **Uniswap v3 pool** and the highest indexed-liquidity direct token/USDG **Uniswap v4 pool**, regardless of later quotes. Thus two preselected pools per token, no pool substitution or adaptive asset swaps. Dexscreener liquidity is only a candidate selector, not executable depth.
- Refresh Robinhood's public canonical registry and multipliers and HL `metaAndAssetCtxs` before quotes. Require current token addresses to match the archived selected addresses. Verify v3 `token0`, `token1`, factory, fee onchain; verify v4 standard no-hook PoolKey hash; verify USDG 6 and stock token 18 decimals, and both quoter contracts deployed. A failed verification stops the run rather than switching pools. Record HL current `growthMode`, `deployerFeeScale`, lot and public base-tier fee factor. Refresh selected multipliers each round; an address change stops.
- At most 64 quoter `eth_call`s and four HL L2 REST calls in each 65-second round. Preflight HL metadata is separated from round 1 by 65 seconds. The complete output directory, including frozen plan, preflight raw data, round observations, and manifest, has an **8,000,000-byte cap**. All attempted quotes/errors are retained up to that cap; hitting it stops the study.

## Observation and interpretation

At a fixed recent block per asset, request direct single-pool **exact-input** AMM buy and sell quotes for each size on both preselected pools. The Uniswap quoter's output includes its pool fee and price impact. The buy uses exact USDG input; the sell uses exact token input `budget / current Robinhood token-price midpoint`. Quote both directions and record request/receipt clocks, block height/time, raw input/output quantities, pool identity and errors. One near-time HL `l2Book` per asset/round supplies a size-walked bid for the AMM-buy/HL-sell direction and ask for the reverse direction. Compare **each route's actual token quantity**, converted to underlying shares by the current registry multiplier; record direct-pool best buy/sell separately without splitting across pools.

The continuous-size HL walk is an **optimistic diagnostic bound** when converted shares fail HL's lot grid. Such a row is explicitly marked `hl_exact_lot=false`, not treated as an executable hedge. Record local quote/book receipt distance and HL source versus fixed-block time; only rows with both ≤2 seconds are called near-time. Compute gross entry gap at USDG≈USDC parity and display the HL **single entry taker fee** plus a separate modeled 5 bp reserve. No future unwind, gas, approval, bridge, inventory, funding, conversion, settlement, private ACK, or actual execution is modeled. Even a positive entry gap is **not arbitrage profit** or an executable full round trip.

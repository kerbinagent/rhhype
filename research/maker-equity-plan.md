# Frozen method: post-market NVDA/XAG public maker quote replay

**Status: audited and frozen before capture.** This is one bounded **post-market** window, not a regular-hours versus overnight comparison. The existing BTC/ETH maker analyzer remains unchanged. The source is the [NVDA/XAG market and risk survey](maker-equity-next.md).

## Predeclared universe, capture, and fee inputs

- Assets NVDA and XAG only. Venues HL `xyz:NVDA`/`xyz:SILVER`, Lighter Core NVDA/XAG, RH Lighter NVDA/XAG. All four maker→hedge directions (HL↔Core, HL↔RH) and both maker sides are evaluated for each asset. Core and RH are separate books.
- One read-only 420-second or 25,000,000-byte compressed hard-cap capture, whichever ends first, after 4 PM ET. Freeze a public metadata plan and hashes beforehand. Collect HL BBO/L2/trades and Core/RH ticker/order book/trades with raw source and receipt times, subscription acknowledgements, generation and nonce information. No authentication, account data, order, or network routing change.
- Public fee scenario, conditional on freshly verified per-asset settings `deployerFeeScale=1`, `growthMode=enabled`, tier-0 unaligned USDC: HL maker **0.3 bp**, taker **0.9 bp**. Core/RH Lighter Standard maker/taker **0 bp**. Recalculate or abort if current asset metadata contradicts those inputs. No assumed maker rebate, referral, staking, or aligned quote discount. Fees apply on each of four own notionals. RH USDG/HL USDC arithmetic is a **conditional parity quote comparison**; conversion execution and cost remain unmodeled, so it cannot establish an executable cross-collateral gain.
- Each route fixes `q = floor(($1,000 / maker best price) / common_lot) × common_lot` using `Decimal`, where current shared lots are 0.001 NVDA share and 0.01 troy oz XAG. Require each leg's minimum base amount, $10 minimum quote, and any maximum base amount **at that leg's first eligible displayed price**, with the identical `q` for maker, hedge, and both exits. A shallow or below-minimum first eligible quote censors immediately. Record market unit and multiplier metadata; abort a route if units or lot lattice cannot be verified.

## Decision, hypothetical flow, and delayed books

1. UTC 5-second decision anchors start after the first three capture seconds; each has its own non-overlapping **trade-flow** window ending at the next anchor. Ten-second outcome windows **overlap** across anchors, so cases are correlated and cannot be summed as portfolio P&L. Primary assumed maker arrival is 1 second after anchor; 0.5 and 3 seconds are predeclared controls. Include all asset/route/side/anchor combinations and report missing gates, not just opening-positive quotes.
2. At decision, both one-level quotes need receipt age ≤1 s, source age ≤2 s, cross-source skew ≤0.5 s, and full `q` displayed hedge size. For assumed maker arrival, select the **first** maker-side quote within one further second whose **source and receipt are both ≥ arrival due** and whose receipt-minus-source age is 0–2 s. Its best price must equal the original and remain uncrossed; then its displayed top size becomes modeled queue ahead. The quote's **receipt time**, not the earlier scheduled due, begins the hypothetical active maker window. Opposite-aggressor uniquely identified trades at or through the maker price count only when both source and receipt fall after this activation and before the next anchor. A **hypothetical full-quantity flow signal** first occurs when cumulative qualifying size **strictly exceeds** displayed queue ahead + `q`. No public trade implies an actual maker order existed or filled.
3. Hedge order-time approximation: due = full-flow **receipt +100 ms** if hedging as HL taker; due = full-flow receipt **+100 ms +300 ms Standard processing** if hedging as Core/RH taker. Select the first quote within the following 1 second for which **both source and receipt timestamps are ≥ due**, quote receipt-minus-source is 0–2 s, and quote source ≥ full-flow source. Only *after* selecting the first time-valid quote test full `q` at the opposite-side best. If shallow, censor as an unresolved hypothetical **unhedged** outcome; do not wait for a later fuller book. Any retained maker-venue trade with source ahead of receipt invalidates that venue/asset's entire maker-flow cohort as timing-unassessable; unaffected venue/assets remain assessable.
4. Exit objective is **5 seconds after selected hedge quote receipt**, with a **hard deadline 10 seconds after full-flow receipt**. Each exit leg has its own due: objective +100 ms for HL taker, objective +100 ms +300 ms for Core/RH Standard taker. Search until the earlier of its due +1 s or the hard deadline for the first observed quote pair where **both source and receipt ≥ their venue-specific due**, source and receipt skew each ≤0.5 s, and quote ages 0–2 s. Only then test full `q` on both exit sides; shallow first pair censors without retry. If an action due exceeds the hard deadline, classify deadline failure rather than inventing an exit. Store each source/receipt timestamp, first eligible price/depth, and deadline-censor reason. No quote is an order fill.
5. If a UTC hourly funding settlement boundary lies from full-flow receipt through the selected exit observation, label **funding-boundary unresolved** and do not report an after-fee round-trip result unless actual signed per-venue funding cash flows are present in that capture. For a missing exit, report separately whether the flow-to-hard-deadline interval crosses an hour. Do not silently assume zero funding.

## Outputs and interpretation

- Preserve every anchor's gate counts for all candidates and the **predeclared decision-time opening-positive subset**. Opening quote allowance subtracts maker entry, hedge taker entry, and an approximate two-taker exit fee hurdle; it never substitutes for an observed closing basis.
- For complete non-funding-boundary paths, compute fixed-`q` long/short displayed cashflow, each of four fees on its own notional, and a separate **5 bp reserve on the larger entry notional**. This generic reserve is a sensitivity, **not measured financing**, which remains unmodeled. Output full-flow cases including missing hedge, shallow exit, deadline failure, terminal capture censor, and their original `q`; never set these to zero or drop them from denominators. Report per-asset, route, side, maker-delay, and post-market session. No pooling with the BTC/ETH sample.
- **No all-taker control in this first v2 study.** Its absence is explicit; a later control would need the same processing-delay and hard-deadline rules. Complete-case mean is selection-biased. Neither trade-through nor a positive conditional quote path estimates actual queue position, fill probability, execution P&L, or a mathematical upper bound. Corporate action, silver oracle, maintenance, RH USDG conversion, and collateral risks remain outside the displayed arithmetic.

Root should review and freeze this method, market plan, and fee-input provenance before any future capture or analysis. Any change after freeze must be versioned and clearly separated from the predeclared result.

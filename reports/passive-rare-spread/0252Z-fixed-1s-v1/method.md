# RH/HL fixed-anchor rare-spread feasibility diagnostic

The implementation manifest must freeze this method before the diagnostic’s first canonical traversal; the archive already exists and this is retrospective exploratory analysis, with no independent holdout claim. This source-only method is separate from the future-study design and its evidence inventory.

Only `data/raw/rh-passive-exit-v1/20260930T0252Z` is admitted: completed 3,000-second RH/HL capture, expected 124,019 records and gzip SHA `c92c269e3bc3bb345beeaf834ad55d0a97601339b4506e36a9397287f8407bb6`. One canonical `rh_maker_events.iter_events` traversal; archive cap 50,000,000 bytes, decoded cap 128,000,000 bytes, record cap 124,019, existing eight MiB line and one-million trade-ID limits. A verified terminal marker is required. No new collection, raw copy, strategy engine, Core comparison, or order endpoint.

Anchors are capture start plus k seconds for k=0..2999, split into five fixed 600-second strata. All canonical events with receipt <= anchor are applied in canonical order, including every event tied at the anchor, before evaluation. No later event repairs an earlier anchor. Book invalidations and venue terminal controls clear depth; changed connection generation clears previous venue books. Trade-only invalidation does not clear depth. All 4 original assets BTC/ETH/NVDA/XAG and budgets 100/250/500/1000 are retained, including missing observations: exactly 48,000 rows.

At an anchor, both books must have positive source and receipt UTC timestamps, source <= receipt <= anchor; source/receipt ages and between-venue source/receipt skews <= two seconds. UTC is not calibrated latency. Each recorded book side is positive, grid-valid, sorted, unique and uncrossed. RH prices use metadata tick, quantities use metadata size step; HL prices use the native dynamic five-significant-figure rule with integer exemption and max 6-szDecimals decimals. Canonical decoder prices/sizes are converted from their decimal string representation; this does not restore precision discarded by the frozen decoder.

Common lot is exact LCM of venue steps. Unchanged quantity is floor(budget/RH best ask/common lot) times common lot, matching the universe screen. RH bid and ask order minimum quantity/notional and maximum quote/quantity are checked. HL quantity rules and both complete depth walks are checked. Recorded HL depth has five levels; insufficient depth excludes, with no deeper liquidity imputed. Maker RH top size is descriptive and does not assert queue capacity or fills. Metadata parity follows the frozen public paper assumptions; unknown contract specs, account fee tier, funding and collateral conversion remain unknown. Capital opportunity cost and funding are excluded from this static margin.

Let q be common quantity, b/a RH bid/ask, S/B recorded HL sell/buy walk notionals, r RH maker rate, h HL taker rate. Margin is q(a-b)+S-B-r*q*(a+b)-h*(S+B)-0.10-0.0005*max(q*b,S). Rates are validated frozen Standard public fees: RH maker zero; native HL 4.5bp, xyz growth-mode 0.9bp. All quantity, grids, walk, fee and strict margin>0 decisions use exact rational arithmetic. Own leg notionals are used. Stress and target match the screen, with no limit-price rescue, dynamic repricing or fee discount.

Report all denominator/exclusion counts by asset, budget and stratum; positive anchors, margins and maximum/median valid margins. Excursions are separate per asset AND budget. A valid nonpositive anchor rearms. Missing/invalid gaps cannot rearm or manufacture independent excursions; bridge gaps within an excursion and report them. The first positive without a prior valid nonpositive anchor is left censored and counted separately, excluded from recurrence eligibility. Primary static recurrence threshold: within one asset at $1,000, >=3 uncensored excursions whose first-positive anchors cover >=2 strata. Smaller sizes are separate exploratory results; correlated budgets are never pooled. Zero valid positives ends this feasibility hypothesis. Passing recurrence supports only inspecting conditional execution odds, not a fill/profit claim or spending the scarce capture slot.

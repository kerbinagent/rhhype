All calls use diagnostic sender and explicit update beneficiary address0x1,
zero value and gasPrice0; these fields are simulation inputs, not evidence of
account ownership, funding, a signed transaction or free real gas. Gas caps:
300000 for each of five metadata getters,1500000 estimate,2000000 update;

discarding state. No real protocol state is changed and no state override is
used. Each update starts independently from the same parent state, so rewards
cannot be summed as one obtainable sequence or portfolio.

The update's returned amount is a provider-reported LP reward. Positive return
permits investigating LP cash conversion, actual transfer/balance effects,
gas and inclusion; it does not demonstrate any of them. Zero estimate alone
is not a rejection because the estimator is approximate/conservative. An
actual update returning zero is zero modeled reward at this state only; an
RPC revert/malformed result remains unavailable and not a zero or loss.
No valuation at virtual price, profit claim, capital estimate or winning-bid
optimization follows from these calls. Every future step needs its own bound.

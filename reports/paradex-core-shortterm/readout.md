# Metadata-stage failure

The frozen launch stopped with an assertion before start time or any WebSocket connection. Core metadata was archived and independently re-normalizes successfully. The second all-markets Paradex request failed a pre-archive limit assertion (decoded response at most 2,000,000 bytes or cumulative compressed metadata at most 98,304 bytes); the exception did not preserve which assertion. Its response was not retained. No book sample, signal or paper order was created. This is an operational failure, with no trading outcome.

A separate corrected collector will request only BTC and ETH market metadata with bounded reads. The failed source, plan and outputs remain preserved; no policy parameters are changed.
